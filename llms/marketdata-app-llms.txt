# Market Data

> Market Data (marketdata.app) is a financial market data provider offering a Bearer-token-authenticated REST API for real-time and historical U.S. stock, options, index, and mutual fund data. All endpoints are served from https://api.marketdata.app/v1 and return JSON or CSV. Usage is billed on a daily API-credit model; multi-symbol responses (bulk quotes, options chains) consume one credit per symbol. Clients must treat HTTP 203 (served from the caching tier) as success.

Important notes:

- Authentication uses a Bearer token in the Authorization header (or a `token` query parameter as a last resort). Tokens come from the customer dashboard.
- Demo without a token: any stock endpoint with AAPL, any options endpoint with an AAPL contract (e.g. AAPL271217C00250000), mutual fund endpoints with VFINX. Historical data only.
- Rate limits: daily API credits (Free 100 / Starter 10,000 / Trader 100,000) or per-minute credits (Quant 10,000 / Prime 100,000), plus a 50-concurrent-request cap. Manage with the X-Api-Ratelimit-Limit / -Remaining / -Reset / -Consumed response headers. The daily counter resets at 9:30 AM Eastern (NYSE opening bell).
- Universal parameters on every endpoint: format=json|csv, dateformat=timestamp|unix|spreadsheet, limit (default 10,000, max 50,000), offset, headers=false (CSV), columns, human=true, mode=cached (paid plans).
- All timestamps use the America/New_York timezone.
- Error envelope: {"s": "error", "errmsg": "..."}; only 200/203 responses consume credits.

## APIs

- [Market Data API docs](https://www.marketdata.app/docs/api/): REST API reference for stocks, options, markets, and mutual funds
- [Stocks API](https://www.marketdata.app/docs/api/stocks/): candles, quotes, bulk quotes/candles, prices, earnings, news
- [Options API](https://www.marketdata.app/docs/api/options/): chains, quotes, expirations, strikes, OCC symbol lookup
- [Markets API](https://www.marketdata.app/docs/api/markets/status/): market open/closed status
- [API status endpoint](https://api.marketdata.app/status/): public service status and 30/90-day uptime, no token required
